**Academic Project: Improving Health in Communities**  
Course/Context: DAT-510: Foundations of Data 2026   
Role: Student Developer / Data Analyst 
Timeline: Summer Semester (10 weeks) 
  
**Project Overview**  
For this project, I followed the complete data lifecycle, from initial cleaning to final analysis and basic visualization, to address  stakeholder questions, delivering actionable insights.  
  
*Key Responsibilities:*   
 * Data Cleaning & Analysis: Process raw dataset, handle missing and invalid values, and conduct exploratory data analysis (EDA) to uncover correlations between environmental pollutants and public health outcomes.
 * Data Visualization: Create easy-to-comprehend visuals for stakeholders to quickly read and understand.
 * Documentation & Presentation: Write comprehensive documentation detailing the end-to-end analytical lifecycle from initial hypothesis to final actionable insights.  
  
*Technologies & Tools Learned:*  
 * Programming Languages: Python, SQL
 * Data Analysis Libraries: Pandas, NumPy, Matplotlib, seaborn, SciPy, scikit-learn
 * Collaboration Tools: GitHub
    
*Key Takeaway:*  

This project helped develop my skills and deepen my understanding of the end-to-end data pipeline- from handling messy data to performing exploratory analysis to the creation of visualizations.
